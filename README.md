# 🤖 Robot-Inclusive

**Робот-помощник для инклюзивного образования** — простая игра на Python, в которой ребёнок учит базовую математику, управляя роботом.

## 💡 Идея

На экране появляется задача, например `Реши: 2 + 2 = ?`, и несколько кубиков с вариантами ответа. Нужно подвести робота к кубику с правильным ответом.

- Неверный кубик серый и перечёркнутый, звучит «Ответ неверный! Попробуй ещё раз.», а робот возвращается на старт.
- Верный кубик — «Верно! Молодец!», и можно брать следующее задание.

Тон подсказок дружелюбный и без давления: ошибка — это не страшно, можно попробовать снова. Поэтому проект подходит для начинающих и для детей, которым важна спокойная, поддерживающая среда обучения.

## ✨ Возможности

- 🎯 **Разные типы задач:** сложение, вычитание, умножение, деление, пропущенное число, числовые ряды, порядок действий, скобки, чётные и нечётные числа, наибольшее и наименьшее число, признаки делимости.
- 📈 **Три уровня сложности**, которые переключаются прямо в игре.
- 🔊 **Голосовая озвучка** заданий и подсказок (необязательно, через `pyttsx3`).
- 🧱 **Преграды** на среднем и сложном уровнях: касание возвращает робота на старт.
- ⏱️ **Таймер** на сложном уровне.
- 📊 **Счётчик** верных ответов и ошибок.
- 🧩 Задачи и поле генерируются случайно, поэтому каждый раунд новый.

## 🎮 Уровни

| Уровень | Кубиков | Преграды | Время | Примеры задач |
|---|:---:|:---:|:---:|---|
| 🟢 Лёгкий | 2 | нет | без лимита | сложение и вычитание до 10, ряды, чётные числа, самое большое число |
| 🟠 Средний | 3 | 2 | без лимита | сложение и вычитание до 20, умножение, пропущенное число, нечётные числа, делимость на 5 |
| 🔴 Сложный | 4 | 4 | 40 секунд | таблица умножения до 9×9, деление, порядок действий, скобки, делимость на 3 |

## 🚀 Установка и запуск

**1. Склонируйте репозиторий**

```bash
git clone https://github.com/<ваш-логин>/robot-inclusive.git
cd robot-inclusive
```

**2. Установите зависимости**

```bash
pip install pygame
```

Для голосовой озвучки (по желанию):

```bash
pip install pyttsx3
```

**3. Запустите игру**

```bash
python main.py
```

> Игра работает и без `pyttsx3`: голос просто будет недоступен.

## ⌨️ Управление

| Клавиша / действие | Что делает |
|---|---|
| ← ↑ → ↓ | движение робота |
| Мышь | кнопки «ПОМОЩЬ», «ЗАДАНИЕ», «УРОВЕНЬ» |
| `T` | новое задание |
| `H` | помощь |
| `1` / `2` / `3` | выбор уровня: лёгкий, средний, сложный |
| `V` | включить или выключить голос |
| `Esc` | выход |

## 🗂️ Структура проекта

```
robot-inclusive/
├── main.py        # вся игра: генераторы задач, уровни, голос, отрисовка
└── README.md
```

Внутри `main.py`:

- **Генераторы задач** (`q_add`, `q_sub`, `q_mul`, `q_div`, …) возвращают текст задачи, верный ответ и неверные варианты.
- **`LEVELS`** описывает уровни: число кубиков, преграды, лимит времени, скорость робота и набор типов задач.
- **`Voice`** — необязательная озвучка через `pyttsx3`.
- **`main()`** — игровой цикл.

## ➕ Как добавить свой тип задачи

1. Напишите генератор, который принимает `k` (сколько нужно неверных ответов) и возвращает `(текст, верный_ответ, [неверные_ответы])`:

   ```python
   def q_double(k):
       a = random.randint(2, 20)
       return f"Реши: {a} × 2 = ?", a * 2, near_wrongs(a * 2, k)
   ```

2. Добавьте его в список `questions` нужного уровня в `LEVELS`:

   ```python
   "questions": [
       lambda k: q_add(k, 10),
       q_double,
   ],
   ```
